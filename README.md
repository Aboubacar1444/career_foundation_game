# MUSIC EMPIRE

Projet de jeu mobile de simulation/RPG de carrière musicale dans un monde persistant multi-pays.

## Vision
Le joueur part d'un niveau professionnel modeste dans un pays choisi, construit sa carrière, débloque progressivement des marchés, langues, styles, médias, villes et responsabilités, puis peut devenir une star, entrepreneur, manager ou fondateur d'un empire musical.

## Principes fondateurs
- Un monde unique et persistant.
- Le pays de départ influence fortement les premières opportunités.
- La progression déverrouille les systèmes ; rien de majeur n'est offert immédiatement.
- Le niveau RPG existe mais reste principalement interne ; le grade professionnel est l'identité publique.
- La carrière peut monter, stagner, décliner et effectuer un comeback crédible.
- Le temps est hybride : persistant, réel lorsque pertinent, mais accélérable.
- Les quêtes et événements racontent une carrière, pas une simple liste de tâches.
- La monétisation vend du temps, du confort et de la personnalisation sans rendre le succès inaccessible gratuitement.
