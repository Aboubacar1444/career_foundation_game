# 07 — LEVELS AND GRADES

## Niveau interne
Le système n'impose pas de plafond fixe à 50. Le niveau peut dépasser 500 si le contenu le justifie.

## Grade professionnel
Le grade est la progression socialement visible.

## Règle
XP élevé ≠ promotion automatique.

Une promotion peut exiger simultanément :
- seuil d'expérience ;
- réputation ;
- audience ;
- certifications ;
- accomplissements ;
- quêtes principales.

## Déclin
Le déclin agit principalement sur la réputation, la visibilité, les opportunités et les revenus. Il ne transforme pas arbitrairement une carrière historique en carrière vierge.
