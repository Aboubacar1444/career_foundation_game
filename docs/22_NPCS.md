# 22 — NPCS

## Types
Producteurs, beatmakers, ingénieurs, managers, artistes, journalistes, animateurs, promoteurs, propriétaires de salles, influenceurs, investisseurs.

## Modèle
Chaque PNJ possède :
- compétences ;
- personnalité ;
- objectifs ;
- relations ;
- loyauté ;
- réputation ;
- disponibilité ;
- mémoire de ses interactions.

Les PNJ peuvent eux-mêmes progresser, décliner, collaborer et concurrencer le joueur.
