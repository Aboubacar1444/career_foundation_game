# 06 — PROGRESSION

## Progression multi-axes
La progression combine :
- XP interne ;
- compétences ;
- grade professionnel ;
- réputation ;
- fanbase ;
- richesse ;
- réseau ;
- accès au monde.

## Déblocages
Les déblocages majeurs exigent des conditions. Exemples :
- activité culturelle ;
- ville ;
- pays ;
- langue ;
- genre ;
- équipement ;
- médias ;
- contrats ;
- tournées.

## Anti-farming
Les gains d'XP doivent dépendre de la difficulté, de la pertinence et du risque d'une action afin d'empêcher le joueur d'exploiter une seule activité répétable.
