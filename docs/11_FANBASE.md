# 11 — FANBASE

La fanbase est segmentée et comportementale.

## Segments initiaux
- locaux ;
- nationaux ;
- internationaux ;
- fans hardcore ;
- fans occasionnels ;
- fans d'un genre ;
- fans sociaux.

## Évolution
Les fans peuvent gagner ou perdre en fidélité selon les sorties, interactions, scandales, absences, performances et changements de style.
