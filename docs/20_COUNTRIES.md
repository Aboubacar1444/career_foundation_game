# 20 — COUNTRIES

Chaque pays possède un profil de marché :
- langues ;
- genres dominants ;
- coût de la vie ;
- coût de production ;
- prix des concerts ;
- réseaux médiatiques ;
- infrastructure ;
- taille de marché ;
- concurrence ;
- opportunités ;
- règles de déblocage.

Aucun pays ne doit être intrinsèquement « meilleur » : chacun échange puissance potentielle, coût, concurrence et accès.
