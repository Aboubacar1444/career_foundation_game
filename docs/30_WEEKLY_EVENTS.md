# 30 — WEEKLY EVENTS

## Vision
Les événements hebdomadaires sont des rendez-vous mondiaux qui donnent une raison de revenir, mais ils doivent être contextualisés par le marché et l'état du joueur.

## Types
- compétition de charts ;
- battle ;
- festival ;
- challenge de production ;
- semaine média ;
- concours de fans ;
- événement économique ;
- campagne caritative fictive ;
- guerre des tournées ;
- événement communautaire mondial.

## Intelligence
Chaque événement reçoit des variables : pays, villes éligibles, genres, grade, réputation, tendances, calendrier, performances récentes et historique des éditions précédentes.

## Anti-répétition
Le moteur doit alterner : format, objectifs, récompenses, marchés, contraintes et narration.

## Récompenses
- monnaie de jeu ;
- réputation ;
- cosmétiques ;
- accélérateurs ;
- XP ;
- visibilité ;
- certificats spéciaux ;
- fragments d'accès à certaines opportunités.

## Classement
Les événements peuvent être individuels, régionaux ou mondiaux. Le matchmaking doit éviter qu'un débutant affronte systématiquement une superstar.
