# 33 — PROGRESSION UNLOCKS

- style musical ;
- langue ;
- ville ;
- pays ;
- activité ;

- matériel ;
- studio ;
- contrats ;
- tournée ;
- métier ;
- gestion d'artistes.

## Déblocage multi-condition
Les gros déblocages peuvent combiner grade, réputation, quête principale, certification, réseau, capital et accomplissements.

## Découverte
Le joueur peut voir l'existence de certains éléments verrouillés sans pouvoir les utiliser. Cela crée une destination claire sans donner immédiatement l'accès.
