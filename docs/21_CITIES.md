# 21 — CITIES

Une ville est une unité de carrière avec :
- scène musicale ;
- salles ;
- studios ;
- médias ;
- événements ;
- coûts ;
- réseau professionnel ;
- spécialisations culturelles.

Des activités peuvent exister dans une ville et ne pas exister dans une autre. Exemple : une scène de battle rap particulière peut être accessible en France sans être disponible au Mali au même moment.
