# 10 — STREAMING

## Plateformes fictives
Exemples de travail : SoundFlow (audio), ViewTube (vidéo), Pulse (short video), Vibe (réseau social).

## Métriques
- streams ;
- vues ;
- abonnés ;
- taux de rétention ;
- viralité ;
- pays ;
- source d'acquisition ;
- revenus estimés.

## Charts
Les classements peuvent être locaux, nationaux, régionaux, continentaux et mondiaux.

## Règle
Les charts sont dynamiques et incluent NPC et joueurs. Le classement ne doit pas être construit uniquement pour flatter le joueur.
