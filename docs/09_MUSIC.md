# 09 — MUSIC

## V0
Un morceau est d'abord un objet de simulation :
- genre ;
- qualité ;
- originalité ;
- production ;
- adéquation au public ;
- potentiel commercial ;
- coût ;
- durée de production.

## Pipeline
Idée → production → mix/master fictif → publication → distribution → performance.

## IA future
La génération audio, les pochettes, les concepts et certaines paroles pourront être générés avec des outils IA, sous réserve de droits et de contraintes de coût.
