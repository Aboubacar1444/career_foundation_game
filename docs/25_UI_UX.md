# 25 — UI UX

## Direction
Premium mobile : RPG + management + simulation musicale, plus ambitieuse visuellement qu'un tycoon classique.

## Inspirations de principe
Lisibilité et gratification des tycoons, profondeur des jeux de gestion, présentation sociale des jeux mobiles modernes.

## Hub
Le téléphone du personnage peut être le hub : carrière, musique, médias, messages, contacts, finances.

## Navigation
Les sections avancées apparaissent progressivement pour refléter les déblocages.

## Profil
Le profil affiche le grade professionnel, réputation, accomplissements, certifications, compétences et historique sans mettre le niveau RPG au premier plan.
