# 03 — PLAYER

## Création
- prénom / nom ou pseudo ;
- homme ou femme ;
- pays de départ ;
- ville de départ ;
- options d'apparence ;
- préférences initiales compatibles avec le marché.

## Philosophie
Le joueur ne choisit pas un personnage déjà puissant. Il choisit un point de départ et construit sa carrière.

## Profil public
Le profil met en avant le grade professionnel, la réputation, les certifications, les accomplissements et les faits marquants.

## Niveau RPG
Le niveau existe pour les calculs internes, la progression et certains déblocages, mais n'est pas affiché en permanence comme une valeur centrale.
